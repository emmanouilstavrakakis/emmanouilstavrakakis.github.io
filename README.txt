WEBSITE FILES

1. Extract the complete website.zip archive.
2. Open index.html in a browser to view the page.
3. Open index.html in a plain-text or code editor to edit it.
4. Keep the assets folder beside index.html. When uploading the website, upload both.

index.html contains the text and CSS styling. It is UTF-8 text.
assets/portrait.png is your photo.
assets/triakis-octahedron.png is the geometric figure.
assets/cv.pdf is the downloadable CV.

The long encoded image and PDF strings have been removed from the HTML.
The email addresses appear as plain text with arobas; there are no mailto links.

If you edit code.txt instead, save the edited file as index.html in this folder.
